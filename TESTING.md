# Проверка шагомера

Сборка: JDK 21, `gradlew.bat testDebugUnitTest assembleDebug lintDebug`.

- Установить debug APK поверх приложения, открыть и разрешить физическую активность.
- Пройти 50–100 шагов с телефоном в кармане; подождать до 10 секунд для обновления накопительного датчика.
- Повторить с выключенным экраном; открыть приложение и проверить итог и календарь.
- Закрыть и снова открыть приложение: итог сохраняется, служба не регистрирует второй слушатель.
- Отказать в разрешении: появляется объяснение и переход в настройки, приложение не падает.
- В календаре проверить соседние месяцы, пустые дни, выбранную дату и возврат между вкладками.
- При смене местной даты начинается новый дневной итог, предыдущая запись остаётся.

## Особенности учёта

Используется TYPE_STEP_COUNTER, при его отсутствии TYPE_STEP_DETECTOR, затем — запасной алгоритм по акселерометру. При отсутствии всех датчиков приложение сообщает об этом.

Первая накопительная отметка — исходная точка: шаги до первого запуска не импортируются. Перезагрузка определяется по `SystemClock.elapsedRealtime()` (время с загрузки уменьшилось) либо по уменьшению самого счётчика — часы телефона для этого не используются. После перезагрузки или принудительной остановки откройте приложение для возобновления службы. Производитель телефона может дополнительно ограничивать её работу в фоне; шаги, сделанные пока служба была остановлена, зачисляются на день следующего показания датчика.

Запасной алгоритм по акселерометру (если нет датчика шагов) работает в отдельном потоке и проверен только синтетическими сигналами в юнит-тестах (`StepDetectorTest`), не на реальной ходьбе.

Дата определяется по времени события датчика в местном часовом поясе. Если одно накопительное обновление включает шаги с обеих сторон полуночи (например, после длительной остановки службы), весь прирост относится к дате этого события: накопительный датчик не содержит времён каждого шага. Дневной итог меняется при следующем обновлении интерфейса/службы, а не требует точного фонового будильника в 00:00.

История старого формата (нулевой индекс месяца) переносится в ISO-даты без изменения оригинальных записей. Даты без записей отличаются от дней с нулём шагов. Дистанция и калории приблизительные.
